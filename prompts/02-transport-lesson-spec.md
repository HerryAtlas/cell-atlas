# 02 · 跨膜运输样板课规格

## 课程定位

- 课程：大学《细胞生物学》
- 章节：第四章 物质的跨膜运输
- 小节：第二节 ATP 驱动泵与主动运输
- 教材页：pp. 62–68
- 模型：`transport`（跨膜运输：通道与泵）
- 时长：10–15 分钟
- 作品内入口：`models.html?model=transport&learn=1`

## 学习目标

完成本课后，学生应能：

1. 区分通道蛋白与 ATP 驱动泵在方向、能量和速度上的差异；
2. 按 E1 → E2 → E1 循环说明 Na⁺/K⁺ 泵的构象变化；
3. 用 3 Na⁺ / 2 K⁺ / 1 ATP 的化学计量解释泵的工作；
4. 预测 ATP 供应或 Na⁺ 梯度改变时，泵速率和膜电位会怎样变化。

### 阶段 2 · 观察机制

Na⁺/K⁺ 泵的 E1–E2 循环拆成 5 步：

1. **3 Na⁺ 从胞质侧结合 E1**
   - E1 对 Na⁺ 亲和力高
   - 方向：Na⁺ 由内向外，逆电化学梯度
2. **ATP 磷酸化泵蛋白**
   - ATP 水解，γ-磷酸基转移
   - 能量耦合改变亲和力，不是直接搬运
3. **E1 → E2，3 Na⁺ 释放到胞外**
   - 构象转换
   - 化学计量：3 Na⁺ 出
4. **2 K⁺ 从胞外结合 E2**
   - E2 对 K⁺ 亲和力高
   - 方向：K⁺ 由外向内
5. **去磷酸化，E2 → E1**
   - K⁺ 释放到胞质
   - 净结果：3 Na⁺ 出、2 K⁺ 入、1 ATP 水解、净泵出 1 个正电荷

- 播放 / 暂停；

### 阶段 3 · 动手探索

预测问题：把 ATP 供应调到 0，同时保持 Na⁺ 梯度不变，泵速率会怎样？

选项：

- 基本不变：泵不依赖 ATP；
- 下降或停止：ATP 是构象循环的能量来源；【正确】
- 上升：没有 ATP 时泵转得更快。

可调条件：

- ATP 供应 0–100%；
- Na⁺ 梯度相对充足度 0–100%；
- 哇巴因（ouabain）开关。

相对速率：

```text
if inhibitor: 0
else: round(100 * atp * (0.45 + 0.55 * gradient))
```

结果反馈：

- 显示相对速率；
- 根据条件给出 observation；
- 对比预测，给出“预测正确/不一致”的反馈；
- 给出机制解释；
- 明确模拟假设。

模拟假设：

- 相对速率模型，不是分子动力学；
- 温度、pH、膜电位、其它转运蛋白恒定；
- 梯度是相对充足度，不是真实离子浓度；
- 哇巴因简化为直接抑制泵循环。

### 阶段 4 · 场景练习

1. **隐藏标签辨认**：点击 Na⁺/K⁺ 泵；答对/答错都有解释，答错可重试。
2. **过程排序**：把 5 步排成正确顺序；正确顺序：
   `na-bind → phosphorylation → e2 → k-bind → dephosphorylation`
3. **结果分析**：哇巴因处理后最可能发生什么；正确选项：
   “泵被抑制，Na⁺/K⁺ 梯度逐渐下降，膜电位受影响”。
