# 04 · 扩展下一节的提示词模板

复制下面模板，替换 `{{...}}`。一次只做一节，不要批量生产未经审校的互动。

---

## PROMPT · 单节垂直切片

你在 Cell Atlas 仓库工作。先读 `AGENTS.md`、`prompts/00-master-context.md` 和 `COURSE-MAP.md`。

为下面这一节实现与「跨膜运输」同等级的导学闭环：

```text
课程：细胞生物学
章：{{chapter_no}} {{chapter_title}}
节：{{section_no}} {{section_title}}
教材页：{{pages}}
模型：{{model_id}}
当前状态：待建设
```

### 1. 内容先行

输出并落盘：

- 3–4 条可测学习目标（用“能解释/能区分/能预测/能标注”开头）；
- 3–5 个可点击结构，每个包含中文名、英文名、标签、概述、机制细节、1 个易错点；
- 3–6 步机制，每步包含标题、机制句、关键点、对应的 3D 状态；
- 1 个预测实验：1–2 个可调条件、2–3 个预测选项、观察量、解释、模拟假设；
- 3 道练习：至少 1 道场景辨认、1 道过程/结构关系、1 道结果分析；
- 每道题的成功反馈和失败反馈都要解释原因，而不是只说“错了”。

### 2. 证据与审校

- 只使用教材或明确可追溯的来源；
- 每个科学结论标注页码范围；
- 不确定的内容标 `TODO: content review`，不要写成确定事实；
- 中英文术语在 `term.zh` / `term.en` 中保持一致；
- 由学科审校者按 `05-content-review-prompt.md` 复核后才能标记完成。

### 3. 3D 与交互

- 复用 `models-scene.js` 的构建器、raycast、选中高亮和标签开关；
- 若模型已有动画，新增导学状态，不要让普通展示状态和导学状态互相覆盖；
- 若没有合适模型，先写内容与交互规格，再评估是否需要新模型；不要为了互动硬造结构；
- 手机端必须能通过折叠/展开完成场景点击。

### 4. 页面与深链

- 模型页入口只在对应模型显示；
- `?learn=1` 自动打开对应导学；
- 教材模型链接带 `&learn=1`；
- 导学头部返回对应章节；
- 在 `COURSE-MAP.md` 把该节状态从“待建设”改为“已打通/待审校”；
- 同步 README 与站内 onboarding 的使用说明。

### 5. 验收

```bash
node build.mjs
node build-demo.mjs
```

- 桌面完整流程；
- 390×844 手机流程；
- 关闭恢复标签、高亮、自动旋转；
- 深链；
- 无 console error；
- 内容审校记录与学生试用记录（未做就明确写“未做”）。

### 6. 输出格式

最后回报：

```text
章节：
模型：
新增/修改文件：
完整流程：
内容依据：
未解决：
构建结果：
commit：
学生试用：已完成 / 未完成
```
